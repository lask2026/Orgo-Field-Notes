# Candidate review results

Local Llama runs create per-case JSON and mode-specific summaries under `llama/chapter-NN/model-name/`. Save downloaded AI Studio findings under `ai-studio/chapter-NN/`.

These files contain candidate findings, not approved corrections or scientific verification. Record a source-supported decision before editing chapter content. Preserve the original response, model, source hash, date, and item ID. Do not mark an entire chapter verified merely because a model reports no findings.

Generated responses are ignored by Git by default; copy adjudicated findings into CHEMISTRY_REVIEW.md and commit confirmed corrections separately. Files remain locally available between runs.
