# Orgo Field Notes

Preserve the v5 visual language and the two modes: Learn & Explore and Guided Practice. Do not add Exam Mode or Mistake Review.

Chapter JSON is the canonical curriculum. Keep reusable behavior in src/. Use zero-based stable atom indices. Every displayed molecule must have a molecular graph, formula, and review note. Distinguish schematic diagrams from molecular structures and experimental data.

Never copy textbook prose, figures, questions, or answer keys into the distributed app. Use the locally supplied curriculum outline; write original teaching material. Do not distribute the EPUB directory. Cite only references actually inspected. Automated graph and answer tests do not constitute independent chemistry verification.

Validate with `python scripts/validate_schema.py`, `node --test tests/unit.test.mjs`, and `node tests/browser.mjs`. Run `node tests/regression.mjs` after cross-cutting UI, persistence, or export changes. The shared test loader resolves a local Playwright installation first, then the installed Codex runtime under the user home; no NODE_PATH setup is needed on this machine. On other machines run npm install and npx playwright install chromium. `node scripts/build.mjs` creates dist/ and the standalone HTML. Run browser tests after each chapter. Preserve corrections and remaining issues in CHEMISTRY_REVIEW.md and PROGRESS.md. Commit each chapter after its checks. Run `node scripts/report.mjs` only after current schema/unit and full browser/regression suites pass; it summarizes those completed runs, not a new test run.

Do not weaken answer validation: preserve commas, hyphens, parentheses, signs, stereochemical descriptors, and units. Revealed or hint-assisted answers must not be counted as independently solved. Never put concealed solution names in accessible labels. Respect reduced motion and keyboard operation. Local storage failures must leave the app usable.

Content-review infrastructure lives under scripts/audit/. Preserve the separation between blind inputs and keyed audits. Local model output must never execute commands or modify curriculum automatically. Keep response validation, context limits, stale-source checks, and partial-result reporting. Regenerate review-packets after content/rendering changes; verify with node --test tests/audit.test.mjs and node scripts/audit/check-packets.mjs. A model review is candidate evidence, not chemistry sign-off.

When a practice stage declares `molecule`, use that graph for rendering, references and atom answers; suppress the exercise-wide diagram and previous-molecule highlights. Include replacement graphs in blind audit inputs and packets without author names/formulas. Keep Newman teaching captions concealed throughout active Guided Practice. PDF fonts must pass the chemistry glyph preflight.

Composition formulas store atom counts without a charge suffix. Use `formulaLabel` when revealing formulas so nonzero net charge is explicit. Two-carbon group labels must not create new atom indices. Atomic `orbitals` schematics show spin occupancy and must distinguish isolated-atom models from molecular structures; do not expose a filled teaching diagram in active quantum practice. Model-specific node and energy claims must state their assumptions. Run `npm test` for all application/review/audit tests.

Write the forward reaction when asking for acid/base equilibrium direction. Keep later quantitative results out of earlier feedback. Distinguish illustrative structures from hypothetical data or general transfer questions. Use `dimensionless` in numeric metadata when appropriate; completed-answer text omits that descriptor as a unit suffix. Acid speciation must label both species without relying on color alone. PDF paragraph rendering must use supported glyphs or fail explicitly; Segoe UI Symbol/DejaVu Sans provides the chemical-symbol fallback.

When changing the substance of an assessment, give its workshop a new ID so prior solved state cannot certify the replacement. Product-naming stages should use existing stage molecule overrides; completion identifies the displayed structure before its formula. Preserve traditional ketal/hemiketal distinctions alongside inclusive acetal terminology. Do not imply separate displayed imine/enamine examples are tautomers. Active walkthrough steps and disabled answer choices require measured contrast in both themes; success styling must stay absent until correct submission. Electron-flow paths must clear visible atom labels while retaining the encoded electron source and target.

Carbon charge labels must remain visible; carbon-charged resonance contributors need explicit H counts where neutral-carbon valence inference would be wrong. Number badges must clear bonds rather than always using an upward offset. Keep resonance contributors distinct from real species/tautomers, and do not teach universal rapid racemization, universal imine/enamine equilibrium preferences or universal conjugation-rate effects. Empty post-answer highlights may be intentional; choose context-appropriate focus per stage instead of making highlights globally sticky. Escape literal less-than signs in HTML educational text.

Spectroscopy identification can set concealStructure to withhold candidate graphs in active practice and blind packets; retain author graphs only in keyed audits/completion. Use a fresh workshop ID when replacing an answer-bearing canvas. Spectrum clusters and broad bands are illustrative; label signals distinctly from atom letters and never equate peak height with integral. Each IR diagram must match its displayed molecule. Keep canonical Hill formula separate from optional conventional displayFormula with identical elemental counts. Phosphate buffers near separate pKa regions, not uniformly across their span. Distillation temperature cutoffs are curriculum heuristics, not physical laws. Native chapter selectors may truncate at narrow widths; full titles must remain visible in wrapped content and Lesson labels must not imply textbook section numbering.

Automated chemistry model review uses scripts/audit/review-panel.mjs and defaults to preview. Keep explicit execution, per-invocation inference limits, phase isolation, source/config/model signatures, raw-output validation and partial/challenge status. Never turn model coverage or agreement into scientificVerification or human sign-off. Existing review-results/expert records came from a key-copying script and are invalid independent-review evidence; preserve their provenance/notice. Credentials belong only in local environment variables. No textbook uploads, model-generated commands, automatic curriculum edits or automatic finding closure. Include tests/review-panel.test.mjs in npm test; mocked providers do not establish live API access or chemistry correctness.

Local reviews stream Ollama responses to avoid the non-streaming HTTP header wait limit. Preserve completion metadata, raw frames, bounded response bytes, partial text on broken streams and UTF-8 glyph integrity across chunk boundaries. Explicit reviewer think is an Ollama-only boolean; omit it for unsupported models. Record thinking/output/cache settings when comparing models. Key matches can coexist with incorrect explanations; retain the qualitative adjudication alongside scores and keep small samples separate from full-chapter completion.
